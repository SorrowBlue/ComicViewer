# Device Operation Rules (端末自動操作・キャプチャの禁止規約)

**Activation:** This rule is **ALWAYS ON** for all files (`**/*`).

## 原則: ユーザーの許可なき端末の自動操作・キャプチャの全面禁止
AIアシスタントは、ユーザーから**明示的な実行指示**（例：「画面をタップして」「スクリーンショットを撮って確認して」など）がない限り、接続されている実機やエミュレータ（Android端末、iOSシミュレータ等）に対する自動操作や画面キャプチャ・録画を**勝手に行ってはなりません**。

### 1. 禁止される操作 (Prohibited Actions)
以下の操作を自律的・独断で行うことは固く禁止します：
- **タッチ・入力操作:** `adb shell input tap`, `adb shell input swipe`, `adb shell input keyevent` 等によるタップ、スワイプ、フリック、キー送信。
- **画面キャプチャ・録画:** `adb shell screencap`, `adb shell screenrecord` 等によるスクリーンショット取得、画面録画。
- **UI自動化ツール・インスペクション:** MCPツール（`mobile-mcp` 等）を用いた自動UIクリック、スクロール、キーストローク入力、画面要素取得など。
- **端末状態の変更:** ロック解除、画面オン/オフ、通知シェードの開閉など。

### 2. 許可される操作 (Allowed Actions)
以下のビルド・インストール・ログ確認などの開発サポートコマンドは実行可能です：
- アプリのビルドおよび端末へのインストール（例: `./gradlew :app:androidApp:installDebug`）
- クラッシュログやデバッグログの確認（例: `adb logcat -d`）
- アプリの起動（例: `adb shell am start`） ※ただし起動後の自動操作は禁止

### 3. 検証が必要な場合の対応
実機やエミュレータでの画面確認や操作が必要な場合は、AIが勝手に端末を操作するのではなく、**ユーザーに操作を依頼する**か、**事前に明示的な確認を行ってください**。
- **推奨する対応例:**
  「端末にアプリをインストールしました。お手元の端末で○○画面を開き、FABのアニメーションや動作をご確認ください。」
